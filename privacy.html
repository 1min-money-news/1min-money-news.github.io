プライバシーポリシー / Privacy Policy

制定日: 2026年10月4日 / Effective: October 4, 2026

このプライバシーポリシーは、YouTube チャンネル「1分マネー」（@1min-money-news）と、その投稿用ツール「1min Money News Uploader」（以下「本ツール」）での情報の扱いを定めます。

1. YouTube API サービスの利用 / Use of YouTube API Services

本ツールは YouTube API サービス（YouTube Data API v3）を利用しています。本ツールを使う人は、YouTube 利用規約に同意したものとします。また、Google による情報の扱いについては Google プライバシー ポリシー（https://policies.google.com/privacy）をご覧ください。

This tool uses YouTube API Services. By using it, you agree to the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

2. 集める情報 / Information we collect

本ツールは、チャンネル運営者本人の Google アカウントで許可を受け、動画の投稿（videos.insert）だけを行います。視聴者や第三者の個人情報、YouTube 上のデータ（視聴履歴・コメント・チャンネル情報など）を読み取ったり、集めたりすることはありません。

The tool only uploads videos to the owner's own channel with the owner's authorization. It does not access, collect or store any personal data or YouTube data of viewers or third parties.

3. 情報の使い方と保存 / Use and storage

投稿に必要な許可の情報（OAuth のトークン）は、運営者の PC の中にだけ保存し、投稿以外の目的には使いません。第三者に提供・販売することはありません。Cookie などで閲覧者の情報を集めることもありません。

The OAuth token is stored only on the owner's computer and used only for uploading. It is never shared with or sold to third parties. No cookies or tracking are used.

4. 許可の取り消しと削除 / Revoking access and deletion

本ツールに与えた許可は、Google アカウントのセキュリティ設定（サードパーティ製アプリのアクセス）からいつでも取り消せます。取り消すと、本ツールは投稿できなくなり、保存していたトークンも使えなくなります。保存しているトークンは、許可の取り消し後、または求めがあった時に、7日以内に削除します。

You can revoke access at any time from the Google security settings page. Stored tokens are deleted within 7 days after revocation or upon request.
