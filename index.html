1min Money News Uploader について

「1min Money News Uploader」は、このチャンネルの運営者だけが使う投稿用のツールです。YouTube API サービス（YouTube Data API）を使い、運営者自身のチャンネルに毎朝の動画を投稿します。一般の方に提供するサービスではなく、利用者の個人情報は集めていません。

1min Money News Uploader is a private tool used only by the channel owner. It uses YouTube API Services to upload videos to the owner's own channel. It is not offered to the public and collects no personal data from viewers.

このツールを使う人は、YouTube 利用規約に同意したものとします。個人情報の扱いは Google プライバシー ポリシーと、当方のプライバシーポリシーに従います。
